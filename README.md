# 🎲 Lucky Draw System

一个基于网页的幸运抽奖系统，支持参会者导入、奖品管理、随机抽奖、补抽、中奖记录管理及个性化界面设置。

## 功能简介

### 👥 参会者管理

- 支持导入参会者名单
- 自动统计参会者数量
- 随机抽取中奖人员
- 防止重复中奖
- 支持重新导入名单

### 🎁 奖品管理

- 支持导入奖品清单
- 实时显示奖品库存
- 自动扣减已抽奖品数量
- 支持重置奖品信息

### 🎯 抽奖功能

- 支持设置单次抽奖人数
- 动态滚动抽奖效果
- 一键停止并公布结果
- 自动记录中奖人员
- 支持多轮抽奖

### 🏆 中奖记录

- 自动保存中奖记录
- 按奖项分类展示
- 支持缺席标记
- 支持补抽功能
- 支持导出中奖结果

### 🎨 个性化设置

- 自定义 Logo
- 自定义背景图片
- 多种主题风格
- 页面透明度调整
- 动画与音效效果

# 🚀 使用方法

## 1. 导入参会者名单

上传参会人员名单文件并完成导入。

建议格式：

```text
张三
李四
王五
赵六
```

---

## 2. 导入奖品信息

准备奖品列表并导入系统。

示例：

```text
一等奖,1
二等奖,2
三等奖,5
幸运奖,10
```

---

## 3. 开始抽奖

1. 选择当前抽取奖项
2. 设置本轮抽奖人数
3. 点击“开始抽奖”
4. 点击“停止并揭晓”
5. 系统自动生成中奖名单

---

## 4. 缺席补抽

如中奖人员缺席：

1. 在中奖记录中标记缺席
2. 进行补抽
3. 系统自动更新中奖结果

---

## 5. 导出中奖结果

活动结束后可导出中奖记录用于保存或打印。

---

# 💾 数据保存

系统会自动保存以下信息：

- 参会者名单
- 奖品配置
- 中奖记录
- 补抽记录
- 页面设置
- Logo
- 背景图片
- 主题配置

刷新页面后可自动恢复数据。
